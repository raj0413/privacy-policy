Application Name: YT Shorts Uploader

1. Introduction

This Privacy Policy describes how YT Shorts Uploader ("we", "our", or "the application") accesses, uses, stores, and protects user data obtained through Google and YouTube API services.

2. Data We Collect and Access

YT Shorts Uploader requests access only to the scopes necessary to upload automated videos to your authorized YouTube channels:

  • Google User Data: Basic profile information (email address) to identify the authorized channel owner.
  • YouTube Data API v3 (https://www.googleapis.com/auth/youtube.upload): Used solely to upload video content, titles, descriptions, and tags to your designated YouTube channel.

3. How We Use Information

The information and tokens obtained through Google OAuth are strictly used to authenticate and execute video uploads to your YouTube channel. We do not sell, rent, monetize, or transfer your personal data or channel contents to any third party.

4. Data Storage and Security

All authentication credentials (OAuth access and refresh tokens) are held privately within secured, encrypted GitHub Secrets of the user's private repository. No credentials or user data are stored on external public servers or shared with unauthorized entities.

5. Compliance with Google API Services User Data Policy

YT Shorts Uploader's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking Access & Data Deletion

Users can revoke access at any time through Google Account Security Settings at Google Third-Party Apps with Account Access. Upon revocation, the application will permanently lose all access to your account.
